      About this app

      How it works

      Source

      Data is pulled from the Parking Summonses dataset on Buffalo's Open Data portal. Pre-aggregated as static JSON committed to this site — no API calls at runtime.

      Heatmap

      Each ticket with a geocoded location is binned to a ~30 m grid and rendered as a weighted heat layer over CartoDB tiles. Lighter areas mean fewer summonses, darker green means more.

      Lookup

      Street names are normalized (e.g. "ELMWOOD AVENUE" → "ELMWOOD AVE") so search matches consistently. The stats card shows total tickets, top three violation types, and a citywide rank.

      Stack

      Static HTML/CSS/vanilla JS. Map rendered with Leaflet and Leaflet.heat. Build script is a single Node 20+ file with no dependencies.

      Not affiliated with the City of Buffalo. Aggregated from publicly available data; counts reflect issued summonses and not necessarily upheld violations.
