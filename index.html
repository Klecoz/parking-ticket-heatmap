          About

          How it works

          Source

          Tickets from Parking Summonses; street centerlines from Highways & Roadways. Both pre-aggregated to static JSON — no API calls at runtime.

          Map

          Each Buffalo street segment is colored by total ticket count (filterable by violation). Click a street to load its stats card. Grey segments had no summonses in this build's date range.

          Lookup

          Street names are normalized ("ELMWOOD AVENUE" → "ELMWOOD AVE") so search matches consistently. Stats card shows total tickets, top three violation descriptions, and citywide percentile.

          Stack

          Static HTML/CSS/vanilla JS. Map via Leaflet; build script is a single Node 20+ file with no dependencies.

          Not affiliated with the City of Buffalo. Aggregated from publicly available data; counts reflect issued summonses, not necessarily upheld violations.
